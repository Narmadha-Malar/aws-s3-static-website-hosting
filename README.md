
# aws-s3-static-website-hosting

A simple static portfolio website hosted on AWS S3 cloud platform using HTML and AWS cloud services.

## About the Project
This project demonstrates how to host a static website using Amazon S3. The website contains basic portfolio information and is publicly accessible through a cloud-hosted URL.

## Features
- Static portfolio website
- Cloud hosting using AWS S3
- Public website access
- Fast and simple deployment
- Beginner-friendly cloud project

## Technologies Used
- HTML
- AWS S3
- AWS Static Website Hosting

## How it Works
1. Create a simple HTML portfolio page
2. Upload the HTML file to AWS S3 bucket
3. Enable Static Website Hosting
4. Configure bucket permissions
5. Access the live website using S3 URL

## Learning Outcomes
- Understanding AWS S3
- Static website deployment
- Cloud storage concepts
- Public access configuration
- Basic cloud project deployment
